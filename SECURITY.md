# Security Policy

## Supported versions

HiveBox is under active development. Security updates are applied to the
latest version on the `main` branch. Older revisions are not supported.

## Report a vulnerability

Do not disclose suspected vulnerabilities in a public GitHub issue. Report
them through [GitHub private vulnerability reporting](https://github.com/MarcPerezdeTudela/devops-hands-on-project-hivebox/security/advisories/new).

Include enough information to investigate the report:

- a description of the vulnerability and its potential impact;
- the affected component or endpoint;
- steps or a minimal example that reproduces the issue;
- any suggested mitigation, if available.

The maintainer will review the report privately and coordinate disclosure after
a fix or mitigation is available.
